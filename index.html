A publicly accessible, decentralized agent network where customers and external AI agents can check hours, filter dietary items, book tables, and place pickup orders — running 100% in-browser with zero inference costs for the shop.

Zero Server Cost (BYOK)

Visitors supply their own LLM key (OpenAI, Gemini, Anthropic, Ollama, or Mock). The shop pays $0 for AI tokens.

Machine Discoverable

Standard agent-manifest.json lets Siri, Otari, or other personal agents automatically find and book services.

Public State Board

Incoming tickets stream into orders.json, enabling transparent order tracking across the open web.

Browser Sandbox Privacy

All inference runs on the client device. Customer data and API keys never touch our servers.
